Open Drop 0.3.0 for Windows x64

Extract the whole ZIP, then double-click opendrop.exe. Keep the DLLs and
platforms folder beside it. No separate Qt installation is needed.

Connect your devices to the same trusted local network. If Windows Firewall
prompts, allow Open Drop on your private network. Discovery uses UDP 45454;
file transfers use TCP 45455 (or the port shown in the app).

Received files: Downloads\Open Drop
Use Connect by address if automatic discovery is unavailable.
This app uses plaintext LAN transfers with confirmation from the receiver.

Built with Qt 6.8.3 (https://www.qt.io/) and MinGW-w64 GCC 13.1.
Qt sources: https://download.qt.io/archive/qt/6.8/6.8.3/submodules/
